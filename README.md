## Projetos

### ScrumFlow — Portal de Certificação em Metodologias Ágeis
Portal web de certificação interna em metodologias ágeis, desenvolvido em
equipe de sete pessoas ao longo de três sprints.

- Avaliações progressivas por módulos, com sorteio de questões balanceadas por dificuldade
- Certificado digital validável publicamente via hash único
- Painel administrativo com CRUD de questões e gestão de tentativas
- Autenticação com JWT · PostgreSQL com DDL/DML explícitos (sem ORM)

`Node.js` `Express` `PostgreSQL` `JWT` `Scrum`

→ [github.com/DEVassos/scrum-flow-abp](https://github.com/DEVassos/scrum-flow-abp)

### Relógio Complexo — React + Python + FastAPI
Relógio analógico que representa os ponteiros como números complexos no
plano de Argand-Gauss.

- Backend Python/FastAPI calcula ângulos e coordenadas a partir de rotações complexas
- Frontend React/TypeScript consome a API e desenha os ponteiros em SVG
- Inclui simulação de tempo, sincronização com horário de Brasília e alarme com sinalização visual e sonora

`React` `TypeScript` `Python` `FastAPI` `SVG` `REST API`

→ [github.com/mparise28-dev/relogio-complexo](https://github.com/mparise28-dev/relogio-complexo)
